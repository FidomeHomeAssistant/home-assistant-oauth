# Privacy Policy

This app is used only by its owner to connect a self-hosted Home Assistant instance to the owner's Google account.

- Data accessed: Nest device data and Google Calendar events for the owner's account.
- Data is stored only on the owner's Home Assistant server and is not sold, shared, or transferred to any third party.
- Access can be revoked at any time at https://myaccount.google.com/permissions.
